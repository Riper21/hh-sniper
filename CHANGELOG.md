## [19.10.2026] — Харднинг — `6ccd876`

### Исправлено
- **Плодящиеся окна approve.** Тикер искал окно по заголовку через `tasklist`
  — и не находил его, когда окно живёт в Windows Terminal: каждую минуту
  открывалось новое, по одной и той же вакансии до пяти вопросов подряд.
  Теперь окно держит pid-лок `data\approve.lock`: второе не откроется, пока
  живо первое; мёртвый лок (криз/перезагрузка) снимается автоматически.
- **Двойные отклики на «одну» вакансию.** Работодатели иногда размещают одно
  объявление дважды (разные id, одно название). Теперь дедуп по ключу
  «название + работодатель»: за всю историю — ровно один отклик; из дублей
  одного прогона отправляется лучшая по скору, дубль из парковки закрывается
  молча, без вопроса и без письма.
- **Скоринг в шторме 429.** Rate limit от LLM-провайдера больше не вешает такт
  на ретраях: fast-fail сразу, сторы целы, следующий такт (через минуту)
  поднимается чистым.

### Изменено
- Статическое письмо — позиционирование AI-инженера (evals, LLM-as-a-Judge,
  агенты, артефакты); дефолт профиля скоринга в коде приведён к боевому
  (ваш профиль по-прежнему живёт в `config.toml`, код не трогается).

**321 тест.**

## [18.10.2026] — Автоответы в чатах hh — `4b4fdf5`

### Добавлено

## [18.10.2026] — Жизненный цикл отклика — `622ae08`

### Добавлено
- «Няня» — отчёт о реакциях работодателей: тишина N дней = отклик «повис».
- Автоподнятие резюме каждые 4 ч в окне 9–19 МСК (hh ранжирует по свежести).
- Уборка неактивных откликов (dry-run по умолчанию).
- Локальный блэклист работодателей.

### Переименовано

  на слово «sniper».

## [18.10.2026] — Первый публичный релиз — `62f8bab`, `a95c38d`

Ядро конвейера (боль: 264 ручных отклика, на ходовые вакансии боты
откликаются каждые ~4 секунды — место в очереди решает скорость):

- Живой поиск каждую минуту по ключевым словам; адаптивное окно — ноут
  спал, первый такт добирает пропущенное.
- Дедуп выдачи и жёсткий гейт по зарплате (пол — ниже даже не скорим).
- LLM-скоринг 0–100 с вердиктами и причинами; LLM используется только
  для скоринга.
- Статическое письмо + **LetterGuard**: числа в письме — только из капсулы
  фактов профиля, ссылки — только из белого списка; промпт-инъекция
  физически не может изменить текст.
- Парковка 45–54 (окно approve: `y`/`n`/`e` + звук) и автопилот 55+
  для вакансий младше 10 минут.
- Windows Task Scheduler: скрытая джоба, лок на повторный такт.
- Вендор-снапшот `hh-applicant-tool` — API-слой и авторизация hh.
