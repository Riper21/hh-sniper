# hh-sniper

Автоматический снайпер вакансий с hh.ru: каждую минуту ищет свежие вакансии
по вашим запросам, оценивает их LLM на соответствие вашему профилю,
прикладывает сопроводительное письмо и откликается — вручную или автопилотом
(только по вакансиям младше 10 минут: на ходовые вакансии боты откликаются
каждые ~4 секунды, и чем раньше отклик — тем выше вы в очереди).

```
поиск hh ──► дедуп ──► жёсткий гейт (пол зарплаты) ──► LLM-скоринг 0-100
                                                       │
                    ┌──────────────────────────────────┤
                    ▼                                  ▼
            скор 45-54 ИЛИ старше 10 мин        скор >= 55 И свежее 10 мин
                    │                                  │
               ПАРКОВКА                         АВТОВЫСТРЕЛ
        (окно "approve" + звук:                 (письмо + отклик
         y = откликнуть,                        уходит сразу)
         n = пропустить,
         e = поправить письмо)
```

- **LLM используется только для скоринга** — письмо статическое, текст не
  подгоняется под вакансию (промпт-инъекция физически не может его изменить).
- **Гвард письма** перед каждым автопилотом: числа в письме разрешены только
  из вашего профиля фактов, ссылки — только из вашего белого списка.
- **Планировщик Windows**: скрытый прогон каждую минуту, адаптивное окно
  поиска (ноут спал — первый такт доберёт пропущенное), лок на повторный
  запуск, окно `approve` с сигналом, когда есть что решить.

## Быстрый старт

Подробно — в [ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md](ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md).
Коротко:

```powershell
# 1. Окружение
python -m venv .venv
.venv\Scripts\pip.exe install -e .\hh-applicant-tool

# 2. Ключи: скопируйте .env.example в .env, заполните (см. файл)
Copy-Item .env.example .env

# 3. Токен hh (один раз, браузер + капча)
.venv\Scripts\python.exe -m sniper.hh_tool ваш@email.ru

# 4. Настройте под себя sniper\config.toml:
#    [scoring].profile — кто вы (грейд/стек/деньги/гео)
#    [letter].static_text — текст письма работодателю
#    [search].queries — слова поиска

# 5. Первый прогон всухую (без реальных откликов)
.venv\Scripts\python.exe -m sniper snipe --dry-run

# 6. Боевой режим — джоба каждую минуту
.venv\Scripts\python.exe -m sniper job on
.venv\Scripts\python.exe -m sniper job status   # проверка
```

## Настройка под себя

Вся персонализация — в одном файле `sniper\config.toml`, правится без
перезапуска (следующий такт подхватит):

| Ключ | Что это |
|---|---|
| `[scoring].profile` | Профиль кандидата → системный промпт скорера: от этого зависит, что получит высокий скор |
| `[search].queries` | Слова полнотекстового поиска hh |
| `[letter].static_text` | Текст письма, уходящего с откликом |
| `[letter].profile` | Факты с цифрами: числа из письма гвард проверяет по ним |
| `[letter_guard].allowed_url_prefixes` | Ваши github/статьи, разрешённые в письме |
| `[scoring].auto_approve_min` | Порог автопилота (55; **0 = всё на ручное решение**) |
| `[fire].max_age_minutes` | Максимальный возраст вакансии для автопилота (10) |

Код модулей содержит те же значения как ПРИМЕР-дефолты (пустой конфиг —
работаем на примере). Пороги, гейты и механика описаны в комментариях
конфига.

## Структура

```
sniper\            конвейер: фильтры, скоринг, письмо, гвард, выстрел, джоба
  config.toml      ЕДИНЫЙ файл персонализации и порогов
  snipe.py         прогон: поиск → дедуп → скоринг → решение → выстрел
  job.py           job status|on|off|run|log — управление планировщиком
scripts\           регистрация задачи, скрытый тик, approve-окно
tests\             176 тестов (pytest)
hh-applicant-tool\ база для API hh (вендор-снапшот, см. ниже)
ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md  подробная инструкция
```
