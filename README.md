# hh-snpr

[![CI](https://github.com/Riper21/hh-sniper/actions/workflows/ci.yml/badge.svg)](https://github.com/Riper21/hh-sniper/actions/workflows/ci.yml)

**Windows / Linux / macOS / Docker (VPS, 24/7)** — один конвейер, четыре
способа тикать: джоба Task Scheduler (Windows), systemd user-timer (Linux),
launchd (macOS), контейнер с рестартом (Docker/VPS). Общий тикер —
`python -m snpr daemon`.

Автоматический снайпер вакансий с hh.ru + модуль прямых контактов
(outreach) в целевые компании. Снайпер: каждую минуту ищет свежие вакансии
по вашим запросам, оценивает их LLM на соответствие вашему профилю,
прикладывает сопроводительное письмо и откликается — вручную или
автопилотом (только по вакансиям младше 10 минут: на ходовые вакансии боты
откликаются каждые ~4 секунды, и чем раньше отклик — тем выше вы в очереди).
Outreach: находит email найм-менеджеров и ML-команды по коммитам GitHub,
карьер-сайтам и Хабру, скорит вакансии и подсказывает прямой контакт к
вашим откликам.

```
ТАКТ (каждую минуту, один процесс, всё внутри — тихие хуки не роняют друг друга)

  ┌─ ПЛАНИРОВЩИК: Windows Task Scheduler │ systemd/launchd │ Docker │ python -m snpr daemon
  ▼
  1. ХУКИ ДО ПОИСКА: автоподнятие резюме (4ч, 9-19 МСК) · автоответы в чатах hh
     · разбор кнопок Telegram («Пустить/Пропустить» = тот же код, что approve)
  2. ПОИСК hh: 6 запросов, адаптивное окно ──► дедуп (seen/applied/parked + имя+работодатель)
  3. КОНВЕЙЕР: жёсткие гейты (пол, грейд, блэклист) ──► LLM-скоринг 0-100
     (бюджет на тик; карточки вакансий — только выжившим)
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
  скор 45-54 или         скор >= 55 И свежее
  старше 10 мин               10 минут
        │                       │
   ПАРКОВКА               АВТОПУСК (письмо +
  (окно approve +          отклик уходят сразу,
  звук; кнопки бота        только статическое
  в Telegram)              письмо + гвард)
        │                       │
        └───────────┬───────────┘
                    ▼
  4. ХУКИ ПОСЛЕ ПУСКА: карточки итогов в Telegram
     · ХАБР-РАДАР: RSS Хабр-Карьеры → префильтры → LLM → TG-карточка
       (кросс-дедуп против hh-истории; отклик руками — API у Хабра нет)
     · OUTREACH-ПОДСКАЗКА: новым откликам ищет прямой контакт в базе
       (найм-менеджер/email) → TG-карточка «кому писать напрямую»
     · SIDECAR-UI: веб-интерфейс 127.0.0.1:8765 жив, упал — перезапуск

OUTREACH — отдельные ручные прогоны (не в тике): snpr outreach career/score/base
  GitHub-коммиты → email ML-команд · Alfa/HuntFlow/Сбер/Авито → email менеджеров
  · Хабр → Telegram экспертов → единая база (outreach.jsonl) + LLM-скоринг вакансий
  → подсказки из базы попадают в тик (п.4), письма НЕ отправляются автоматически

UI (127.0.0.1:8765): дашборд · контакты · скоринг (hh+карьер вместе) ·
  мастер настройки (резюме → LLM-черновики → config.toml) · управление джобой
```

## Ключевые свойства

- **LLM используется только для скоринга** — письмо статическое, текст не
  подгоняется под вакансию (промпт-инъекция физически не может его изменить).
- **Гвард письма** перед каждым автопилотом: числа в письме разрешены только
  из вашего профиля фактов, ссылки — только из вашего белого списка.
- **Тикер на любой ОС**: Windows — скрытая джоба каждую минуту
  (адаптивное окно поиска: ноут спал — первый такт доберёт пропущенное,
  лок на повторный запуск); Linux/macOS — `scripts/unix/install.sh`
  (systemd/launchd-юнит) или `python -m snpr daemon`; Docker на VPS —
  `docker compose up -d --build`, контейнер тикает 24/7. Когда есть что
  решить — окно `approve` + сигнал (на Linux/macOS/Docker — BEL в логах).
- **Жизнь отклика**: автоподнятие резюме каждые 4 ч в рабочие часы
  (буст видимости), «няня» — отчёт о реакциях работодателей, автоответы
  на вопросы ИИ-скринеров в чатах, уборка неактивных откликов, локальный
  блэклист работодателей.
- **Модуль outreach** (06.11): база прямых контактов целевых компаний —
  найм-менеджеры (email из карьер-сайтов: Alfa API, HuntFlow, Сбер, Авито),
  ML-команда (email из коммитов GitHub), эксперты (Telegram из Хабра).
  LLM-скоринг карьер-вакансий тем же профилем, что и снайпер, — видно,
  насколько подходит и кому писать. Роль конфигурируема: `[outreach].
  role_keywords` (QA/фронтенд/DevOps — словарь ключевых слов вместо ML-дефолта).
- **Веб-интерфейс** (`python -m snpr outreach ui`, только 127.0.0.1):
  дашборд, контакты с источниками, вкладка «Скоринг» (hh + карьер-вакансии
  с найм-менеджерами), **мастер настройки без правки конфигов** (вставьте
  текст резюме — LLM составит черновики профилей скоринга/письма и словарь
  роли), управление джобой из браузера (включить/выключить/прогнать такт).
  Ярлык `UI_Снайпер.cmd` — двойной клик, UI поднимется и откроется сам.

## Быстрый старт

Подробно — в [ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md](ИНСТРУКЦИЯ_ПОЛЬЗОВАТЕЛЯ.md).
Коротко:

```powershell
# 1. Окружение
python -m venv .venv
.venv\Scripts\pip.exe install -e .\hh-applicant-tool

# 2. Ключи: скопируйте .env.example в .env, заполните (см. файл)
Copy-Item .env.example .env

# 3. Токен hh (один раз, браузер + код)
.venv\Scripts\python.exe -m snpr.hh_tool ваш@email.ru

# 4. Настройка под себя: snpr\config.toml — ИЛИ через UI-мастер
#    (вставить резюме → черновики профилей → «Сохранить»)

# 5. Первый прогон (сухой — без реальных откликов)
.venv\Scripts\python.exe -m snpr sne --dry-run

# 6. Включить автопилот (минутная джоба)
.venv\Scripts\python.exe -m snpr job on
.venv\Scripts\python.exe -m snpr job status   # проверка
```

Linux/macOS: те же команды (`python` вместо `.venv\Scripts\python.exe`),
`job on` подскажет установку юнита (`scripts/unix/install.sh`) или tmux.
VPS для работы 24/7: `docker compose up -d --build` (токен hh и том data/ —
см. ИНСТРУКЦИЮ, «Постоянный режим — VPS»).

## Настройка под себя

Всё в одном файле `snpr\config.toml`, перечитывается каждый такт:

| Секция | Что там |
|---|---|
| `[scoring].profile` | профиль для LLM-скоринга: кто вы, стек, грейд, деньги |
| `[search].queries` | поисковые запросы снайпера (hh) |
| `[letter].static_text` | текст письма, идущего с откликом |
| `[letter].profile` | факты о вас: числа из письма гард разрешает только отсюда |
| `[letter_guard].allowed_url_prefixes` | ваши github/статьи, разрешённые в письме |
| `[scoring].auto_approve_min` | порог автопилота (55; **0 = всё в парковку**) |
| `[send].max_age_minutes` | свежесть вакансии для автопуска (10) |
| `[outreach].role_keywords` | словарь роли outreach (пусто = ML/AI-дефолт) |

Или не трогайте конфиг вообще: мастер в UI (вкладка «Настройка») составит
черновики из вашего резюме через LLM.

## После отклика

- **Автоподнятие** (сам, в такте): POST /resumes/{id}/publish каждые 4 ч
  в окне 9-19 МСК — hh ранжирует по свежести поднятия. Ручное:
  `python -m snpr raise [--force]`.
- **Няня** (`python -m snpr nanny`): движение по вашим откликам — ответы,
  просмотры, смены статусов; снапшоты в `data\nanny.jsonl`, между
  прогонами показывается только разница.
- **Ответы в чатах** (`python -m snpr reply`): автоответы на вопросы
  ИИ-скринеров (кнопочные — точное совпадение, свободный текст — LLM строго
  из фактов профиля + гвард; люди — только вручную). Анти-дубль
  (`data\replied.jsonl`), каденция `[reply]`.
- **Уборка** (`python -m snpr cleanup`): отзыв зависших откликов
  (нет движения 14 дней). По умолчанию — сухой прогон; применение — `--apply`.
- **Блэклист** (`python -m snpr blacklist add <vacancy_id>`).
